# Pollinations Image Studio

A clean, responsive web-based image generation application powered entirely by the public open endpoints of Pollinations.ai.

## Features
- Instant text-to-image generation directly inside the web browser.
- Fully responsive user interface styled with dark mode elements.
- Uses no private tokens or sensitive backend keys to ensure frontend safety.
